# Model inventory and reporting scope

Original CNN and SpikingCNN checkpoints are preserved by fold and seed. Only fold 0 (five seeds) of SpikingCNN1D belongs to the reported, incomplete exploratory study; its later-fold files remain archival and are excluded from manuscript aggregates. Inference checks were performed on the stored files, which does not expand the reported study.

Regenerated feature classifiers, reservoir/Ridge exports and precision-specific fitted readouts are under `../../generated/`. They are labelled as regenerated rather than original recovered fits. See `../../STUDY_SCOPE.md` and `../../generated/tables/S2_model_exports.csv`.
